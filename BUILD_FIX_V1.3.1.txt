Healthome V1.3.1 - Android bundle fix

Root cause from EAS/Metro error:
App.js imports `expo-status-bar`, but the package was missing from package.json.

Fixed:
- Added expo-status-bar ~3.0.9 (Expo SDK 54 recommended version).
- Added expo-status-bar config plugin.
- Version 1.3.1 / Android versionCode 6.
- Kept APK EAS profile.

Build:
1. npm install
2. npx expo export --platform android
3. npx eas-cli@latest build -p android --profile apk --clear-cache
