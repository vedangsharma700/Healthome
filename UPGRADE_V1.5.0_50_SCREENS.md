# Healthome V1.5.0 — 50-screen professional expansion

This release keeps the working V1.4.0 baseline and adds 19 dedicated patient workflows, bringing the intended patient experience to 50 screen states when combined with the existing 31.

## Added workflows
1. Doctor Profile
2. Choose Specialty
3. Pre-Consultation Intake
4. Consultation Confirmation
5. Video Consultation
6. Instant Consultation
7. Home Care Hub
8. Home Care Service List
9. Home Care Service Details
10. Care Package Details
11. Lab Test Details
12. Lab Sample Collection
13. Health Articles
14. Symptom Checker
15. Medicine Product Details
16. Cart & Checkout
17. Order Tracking
18. Wallet Transactions
19. Account & Security

These are intentionally implemented as reusable, backend-ready workflow screens rather than hard-coded fake transactions. Real payments, consultations, medical decisions, and provider availability still require secure backend integrations.
